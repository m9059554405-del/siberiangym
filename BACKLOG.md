# Рабочий backlog

Короткий оперативный список незавершённых задач. Подробные требования, ограничения и юридический контекст находятся в [`prompt-dorabotki-dlya-kluba.md`](prompt-dorabotki-dlya-kluba.md). Полностью завершённые задачи не дублируются здесь: реализация и проверки фиксируются в [`CHANGELOG.md`](CHANGELOG.md).

## Правила ведения

- Одна строка — один ID из исходного backlog.
- `не начато` — работа по незакрытому объёму не начата.
- `в работе` — есть реализация, но остались явно указанные ограничения или хвосты.
- `заблокировано` — требуется внешнее решение, доступ или действие владельца.
- Перед началом работы проверить `git status`, `git diff` и последние коммиты.
- Вести одновременно только одну задачу со статусом `в работе` как текущую.
- Завершать задачу только после проверок и записи в `CHANGELOG.md`.
- Один коммит — одна логическая задача; в сообщении коммита указывать ID.
- После полного закрытия убрать строку из этого файла: источник истории — `CHANGELOG.md` и Git.
