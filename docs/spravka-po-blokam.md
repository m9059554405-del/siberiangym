# SiberianGym — справка по блокам программы

Развёрнутая справка по каждому разделу веб-приложения фитнес-клуба. Все скриншоты сняты с демо-стенда `http://201.51.19.13:8080` (точка сети «100 Друзей», тестовые данные) 2026-09-23 и лежат в папке `docs/screenshots/`.

## Роли и общее устройство

Приложение — Single Page Application (React + Vite), один фронтенд для всех ролей. После входа интерфейс подстраивается под роль пользователя:

| Роль | Кто это | Стартовая страница |
|---|---|---|
| **CLIENT** | Клиент клуба | `#/client/payments` |
| **TRAINER** | Тренер | `#/trainer` |
| **STAFF** | Администратор точки | `#/staff` |
| **CEO** | Владелец/управляющий сети | `#/ceo` |
| **SYSADMIN** | Системный администратор | `#/admin` |

Сверху — шапка с логотипом, бейджем роли, выбором точки сети (для CEO/STAFF) и кнопкой выхода. Навигация: у клиента — горизонтальные вкладки, у остальных ролей — боковое меню.

![Экран входа](screenshots/auth-login.png)

**Вход**: email + пароль, ссылки «Забыли пароль?» (восстановление по email) и отдельный экран подтверждения входа по одноразовому коду (2FA), если он включён для учётной записи.

## Согласие на обработку персональных данных (152-ФЗ)

При первом входе клиента доступ ко всему приложению блокирует экран «Прежде чем продолжить». Нужно раскрыть и подтвердить три обязательных согласия (обработка ПДн, фото/видео для показателей, информирование о занятиях); маркетинговые согласия — опциональные переключатели. Согласие можно отозвать в любой момент в разделе «Мои данные»; версия текста фиксируется.

![Экран согласий 152-ФЗ](screenshots/client-consents.png)

# Разделы клиента (CLIENT)

## Оплата (`#/client/payments`)

Главный экран клиента. Сверху — карточка текущего абонемента: название, статус, дата окончания, тренер и QR-код для входа в клуб. Ниже:

- **Промокод** — ввод кода перед покупкой, скидка применится к следующему заказу;
- **Абонементы** — разовое занятие, месяц, пакеты на 10/20 занятий с ценами и кнопкой «Купить»;
- **Тариф сопровождения** — Базовый / Ведение / Индивидуальные тренировки (подписка на работу с тренером);
- **Приведи друга** — персональный реферальный код и активация кода друга (обе стороны получают скидку);
- **Персональные и групповые тренировки** — цены разовых и пакетных тренировок (оплата при записи в «Календаре»);
- **Обратная связь директору** — прямые сообщения, видимые владельцу клуба, с историей;
- **Мои персональные данные** — статусы всех согласий с кнопками «Дать/Отозвать», выгрузка своих данных и запрос на удаление.

![Оплата](screenshots/client-payments.png)

## Календарь (`#/client/calendar`)

Записи на занятия: групповые занятия по дням с фильтрами и персональные слоты тренера. Если персонального тренера нет — показывается подсказка со ссылкой на вкладку «Тренер». Отмена записи ограничена окном отмены: при поздней отмене кнопка блокируется с пояснением «свяжитесь с администратором». Оплата персональной тренировки списывается при записи.

![Календарь](screenshots/client-calendar.png)

## Магазин (`#/client/shop`)

Витрина клуба по категориям: «Кабинка для переодевания», «Вода», «Еда и снеки». Товар берутся из остатков склада точки; заказ оформляется в пару кликов, оплата — при получении на рецепции.

![Магазин](screenshots/client-shop.png)

## Упражнения (`#/client/exercises`)

Тренировочный дневник. Тренер составляет программу по дням (упражнения, подходы, повторы, вес); клиент отмечает выполнение, вносит фактические веса по каждому подходу и завершает тренировку. Ниже — «Выполненные тренировки» с историей. Если программа не составлена, показываются соответствующие подсказки.

![Упражнения и программа](screenshots/client-exercises.png)

## Тренер (`#/client/trainer`)

Каталог тренеров точки со специализациями («Выбор тренера»): карточки с биографией и направлением; выбор тренера подключает персональные слоты в «Календаре» и программу тренировок.

![Выбор тренера](screenshots/client-trainer.png)

## Новости (`#/client/news`)

Лента публикаций клуба (пишут STAFF/CEO), рядом — «Рейтинг по нагрузке» между клиентами по объёму выполненных тренировок.

![Новости клуба](screenshots/client-news.png)

## Прогресс (`#/client/progress`)

Дневник результатов: изменение нагрузки по группам мышц относительно предыдущего периода, замеры тела (вес, объёмы) с динамикой, фото «было/стало» в полный рост, фото питания по приёмам пищи, личные данные и женский календарь (отслеживание цикла).

![Прогресс](screenshots/client-progress.png)

## Уведомления (`#/client/notifications`)

Подписка на push-уведомления браузера (разрешение запрашивается один раз) и история уведомлений: напоминания о записях, ответы директора и т.д.

![Уведомления](screenshots/client-notifications.png)

# Разделы тренера (TRAINER)

## Список подопечных (`#/trainer`)

Все клиенты тренера с фильтром по формату работы: «Персонально», «Группы», «Самостоятельно». По каждому: имя, дата прихода в клуб, тариф, бейджи формата и статуса абонемента (Активен / Заморожен / Истёк).

![Список подопечных](screenshots/trainer-clients.png)

## Карточка подопечного (`#/trainer/clients/:clientId`)

Полная картина по клиенту: прогресс рабочего веса по ключевому упражнению, текущая программа тренировок, история тренировок с выполненными подходами, изменение нагрузки по мышцам за 30 дней, замеры, загруженные клиентом фото (еда и «было/стало»). Отсюда тренер ведёт программу и контролирует дисциплину.

![Карточка подопечного](screenshots/trainer-client-detail.png)

## Моё расписание (`#/trainer/schedule`)

Расписание тренера: персональные слоты и групповые занятия с нагрузкой по дням.

![Моё расписание](screenshots/trainer-schedule.png)

# Разделы администратора точки (STAFF)

## Клиенты (`#/staff`)

Рабочий журнал рецепции: поиск по всем клиентам точки, карточки с абонементами и контактами, создание нового клиента. Учитываются клиенты с других точек сети: если у клиента сетевой абонемент, карточка может быть заведена на другой точке — такой клиент находится и обслуживается здесь.

![Клиенты](screenshots/staff-clients.png)

## Гости и лиды (`#/staff/leads`)

Карточки потенциальных клиентов (например, по звонку из Instagram): имя, контакт, источник, дата визита; список карточек точки для последующей проработки.

![Гости и лиды](screenshots/staff-leads.png)

## Вход (`#/staff/checkins`)

Скан QR-кода клиента на входе: камера читает код из приложения клиента, повторный скан того же клиента в течение минуты не записывается. Под сканером — журнал последних проходов точки.

![Вход по QR](screenshots/staff-checkins.png)

## Заказы (`#/staff/orders`)

Кассовый контур: заказы «Ожидают оплаты» (создаются покупками клиента), подтверждение оплаты и выдача фискального чека; оформление возврата по оплаченному заказу и очередь «Ожидают чека возврата».

![Заказы](screenshots/staff-orders.png)

## Новости клуба (`#/staff/news`)

Публикация объявлений в клиентскую ленту: текст появляется у клиентов сразу после отправки.

![Новости клуба](screenshots/staff-news.png)

## Уборка (`#/staff/cleaning`)

Чек-лист уборки на сегодня с ответственным: пункты по зонам (пол, освещение, поверхности, зеркала, санузлы, шкафчики, окна), отметки выполнения; ниже — история уборок по дням.

![Уборка](screenshots/staff-cleaning.png)

## ППР — плановое обслуживание (`#/staff/equipment`)

Реестр оборудования клуба с планами профилактических работ: что обслуживать, когда просрочено. Просроченные задачи подсвечиваются и требуют внимания.

![ППР](screenshots/staff-equipment.png)

## Склад (`#/staff/stock`)

Та же страница склада, что у CEO, в разрезе своей точки: приходы, списания, инвентаризации, остатки и сроки годности.

![Склад](screenshots/staff-stock.png)

# Разделы владельца сети (CEO)

Меню CEO охватывает всю сеть; в шапке — переключатель точки. Часть страниц сетевые (без привязки к точке), часть — по выбранной точке.

## Загрузка тренеров (`#/ceo`)

Список тренеров с загрузкой и карточкой каждого тренера. На странице: «Сертификаты требуют внимания» (просроченные и истекающие за 30 дней), «Клиенты по тренерам» с разбивкой по формату занятий, «Подробности по тренерам» — клик открывает подопечных и оплаты. Через «Новый тренер» заводится тренер. В карточке тренера: согласие сотрудника на обработку ПДн, «Отсутствие и уход» (массовая обработка расписания и подопечных), сертификаты, «Точки сети» (где ведёт занятия), подопечные и результаты, платежи, связанные с тренером.

![Загрузка тренеров](screenshots/ceo-load.png)

## Посещаемость (`#/ceo/attendance`)

Аналитика визитов: динамика по дням, разбивка по неделям, «Время посещений» (в какие часы клиенты ходят в клуб) и «Занятость тренеров по времени суток» (сумма персональных слотов и групповых занятий по часам).

![Посещаемость](screenshots/ceo-attendance.png)

## Серии занятий (`#/ceo/series`)

Шаблоны повторяющихся занятий («Йога по Пн и Чт в 19:00»): занятия создаются в расписании автоматически; серию можно целиком отменить, есть список серий с управлением.

![Серии занятий](screenshots/ceo-series.png)

## Вход по QR (`#/ceo/checkins`)

Сетевой журнал проходов и скан QR — тот же механизм, что у администратора, с точки зрения владельца.

![Вход по QR](screenshots/ceo-checkins.png)

## Выручка (`#/ceo/revenue`)

Финансовая сводка сети: динамика выручки (дни — за 30 дней, месяцы — за всю историю), разбивка по источникам (абонементы, тренировки, магазин), топ тренеров по выручке, реестр транзакций с чеками и возвратами, «Выручка по точкам» — вся сеть одной сводкой.

![Выручка](screenshots/ceo-revenue.png)

## Клиентская база (`#/ceo/clients`)

Сегментация клиентов: «Формат занятий» (персонально/группа/самостоятельно), «Статус абонементов», «Тарифы абонементов» с ценой на точке и на всей сети, «Клиенты со сменой тренера или формата» — история переходов, видимая тренерам.

![Клиентская база](screenshots/ceo-clients.png)

## Точки сети (`#/ceo/gyms`)

Управление площадками: создание/переименование/удаление точки, сводка точки (клиенты, тренеры, админы, выручка). Блоки:

- **Залы точки** — создание залов (тренажёрный, гимнастический, единоборств) с назначением тренеров и цен за занятия; последний зал удалить нельзя;
- **Часы работы** — расписание по дням недели; занятия и слоты вне часов отклоняются, серии пропускают это время;
- **Администраторы сети** — логины STAFF и их точки, перенос между точками одним выбором, создание нового администратора и отключение доступа;
- **Тренеры на точках** — назначение тренера на одну, несколько или все точки.

![Точки сети](screenshots/ceo-gyms.png)

## Заказы (`#/ceo/orders`)

Сетевой реестр заказов: открытые и оплаченные заказы, чеки, возвраты — контроль кассового контура по всей сети.

![Заказы](screenshots/ceo-orders.png)

## Продажи (`#/ceo/sales`)

Инструменты продаж: **промокоды** (публичные акции и персональные бонусы, скидка на любой заказ), **реферальная программа** «Приведи друга» (обе стороны получают персональный промокод), **корпоративные договоры** (сотрудники компаний-партнёров со скидкой и сводная ведомость для бухгалтерии).

![Продажи](screenshots/ceo-sales.png)

## Склад (`#/ceo/stock`)

Складской учёт сети: «Скоро истекает срок годности», остатки по товарам с раскрытием партий (полка/склад), история операций (приходы, списания, инвентаризации) и справочник товаров. Отдельные формы: «Приход товара», «Списание товара», «Инвентаризация».

![Склад](screenshots/ceo-stock.png)

## Обслуживание клуба (`#/ceo/maintenance`)

Настройка эксплуатации точки: **зоны уборки** (переименование/удаление неиспользуемых — из них генерируются чек-листы), сегодняшний чек-лист с ответственным, история уборок и обращения клиентов (сообщения из приложения).

![Обслуживание клуба](screenshots/ceo-maintenance.png)

## Рассылки (`#/ceo/offers`)

«Предложения для рассылки»: создание предложения с выбором целевой аудитории — оно появится у подходящих клиентов; управление активными и архивными предложениями.

![Рассылки](screenshots/ceo-offers.png)

## Журнал изменений (`#/ceo/activity`)

Аудит-лог действий во всех приложениях сети: кто, что и когда менял — для контроля персонала и разбора инцидентов.

![Журнал изменений](screenshots/ceo-activity.png)

## Как проверить всё живьём

1. Откройте `http://201.51.19.13:8080`.
2. Войдите по учётным записям из таблицы выше — интерфейс и меню подстроятся под роль.
3. Клиентские сценарии (покупка абонемента, запись на занятие, дневник тренировок) удобно проходить параллельно в двух окнах: клиент + администратор.
